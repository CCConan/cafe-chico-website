# Café Chico · Family-run café website

A single-page (Home + Story + Contact) + dedicated Menu site for **Café Chico**, a small family-run café at 185 St Helens Rd, Bolton BL3 3PS.

## Quick start

Open `index.html` in a browser, or serve the folder:

```bash
cd "Cafe Chico website"
python3 -m http.server 8765
# → http://127.0.0.1:8765/
```

## Design system

- **Palette**: warm cream paper (`oklch(97% 0.012 80)`), espresso brown text, burnt-sienna accent (`oklch(48% 0.10 25)`), deep brick for hero/dark sections, soft antique gold for menu-hero kicker.
- **Type**: serif display (DM Serif Display via Google Fonts, falls back to Iowan Old Style / Charter / Georgia) + Inter for body + system mono for metadata kickers.
- **Hand-drawn flourishes**: inline SVG library — squiggle dividers, heart wreath, spoon-fork-cross, bicycle silhouette, coffee cup. All drawn from inline `<defs>`, no external requests.
- **Animation**: `cubic-bezier(.2, .8, .2, 1)` everywhere. `prefers-reduced-motion` honoured globally.
