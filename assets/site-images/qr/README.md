# Café Chico — QR codes（真嘅，可掃）

全部由 `npx qrcode` 本機生成（非 AI 假圖），已驗證 URL 正確。

| 檔案 | 用途 | 內容 | 建議 |
|---|---|---|---|
| `website.png` (512px) | 網頁用 | https://www.cafechico.co.uk | 網站／社交貼文 |
| `tiktok.png` (512px) | 網頁用（Menu 頁 hover 彈出） | https://www.tiktok.com/@cafechico | 網站 |
| `instagram.png` (512px) | 網頁用（Menu 頁 hover 彈出） | https://www.instagram.com/cafechico_uk/ | 網站 |
| `website-1024.png` / `-2048.png` | **印刷用** | 同上 | 菜單／傳單；1024 ≈ 8.7cm @300dpi |
| `tiktok-1024.png` / `-2048.png` | **印刷用** | 同上 | 紅色 #14140C 底改為純黑、留白邊（quiet zone 4 格） |
| `instagram-1024.png` / `-2048.png` | **印刷用** | 同上 | 建議印刷最小 2cm × 2cm |

## 印刷注意
- 印刷版用純黑 `#000000` + 白底，**唔好**用低對比顏色或加圖案底
- 四周留白（quiet zone）係 QR 嘅一部分，**唔好裁走**
- 最少印 2cm × 2cm；菜單上建議 2.5–3cm
- 印刷前用手機試掃一次（iPhone / Android 各一次）
